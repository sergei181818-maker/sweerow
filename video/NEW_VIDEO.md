# Как сделать новое видео (инструкция для Claude)

Эталон качества — `video/tilly/` (персонажи с лицами и эмоциями: функции `toon()` и `face()`, пузыри `bubble()`, HUD-плашка `hud()`, субтитры ниже лиц). `video/onoda/` — старый стиль силуэтов, не использовать. Новое видео = новая папка `video/<slug>/`.

1. `bash video/setup.sh` (один раз в контейнере).
2. `cp video/onoda/{tts.py,render.js,music.py,mix.sh} video/<slug>/` и скопировать `render.html` как основу.
3. **Сценарий** `script.json`, 55–75 сек, 15–22 реплики:
   - Хук в первые 2 сек (шок-факт/цифра/вопрос). Поворот на ~50–60% («А теперь самое странное…»).
   - Короткие фразы. В `text` числа словами, сложные имена упростить для голоса; в `sub` — цифрами.
   - Факты проверять через WebSearch. Финал — CTA «Подпишись…».
4. **Сцены** в `render.html`: объект `S.<scene>` на каждую сцену из `script.json`. Переиспользовать
   хелперы (jungleLayer, soldier/person, paper, stamp, label, glow, plane, fireflies, sky), рисовать
   новые силуэты/предметы под историю. Каждые 3–5 сек — новое визуальное событие (печать, счётчик,
   появление карточки, смена плана). Обновить `stampTimes()` и события в `setup()` под новые сцены.
   Стиль подбирать по кадрам роликов-доноров (research/data/frames/*.jpg), но рисовать своё.
5. `python3 tts.py ~/voices/ru_RU-ruslan-medium.onnx build` → `python3 ../check_voice.py build/voice.wav`,
   переписать фразы, которые распознались криво.
6. `node render.js build --preview 2,8,15,...` (кадр каждые ~5 сек), склеить в контакт-лист
   (`ffmpeg ... tile`), посмотреть Read'ом и исправить: персонажи не теряются, текст не обрезан,
   субтитры не перекрывают ключевые надписи.
7. `node render.js build && python3 music.py build && ./mix.sh build build/<slug>.mp4`.
   Проверить: `ffprobe` — аудио AAC 44100 Гц стерео (иначе на телефоне нет звука!), громкость ~-14 LUFS.
8. Отправить mp4 в чат (SendUserFile) с подписью: название, длительность, описание + хэштеги для TikTok.
9. Закоммитить исходники (mp4 не коммитим) и запушить.
