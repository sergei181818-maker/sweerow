# Генератор шортсов «Что бы ты сделал?»

Сценарий в JSON превращается в готовое вертикальное видео 1080×1920:
нейро-озвучка, анимированная графика, субтитры «как в ТикТоке» (слово в слово),
звуковые эффекты, таймер и призыв писать в комментарии.

## Как сделать новый эпизод

1. Скопируйте `episodes/ep01_les.json` и поменяйте тексты.
2. Запустите:

   ```bash
   pip install edge-tts numpy
   python3 shorts/make_short.py shorts/episodes/ep02_xxx.json
   ```

3. Результат появится в `shorts/out/<id>/`:
   - `<id>.mp4` — готовое видео;
   - `post.txt` — название, описание, хештеги и текст закреплённого комментария с ответом.

Нужны: Python 3, Node.js с Playwright (Chromium) и ffmpeg.

## Файлы

- `make_short.py` — конвейер: озвучка → звук → таймлайн → рендер.
- `template.html` — вся графика и анимации (цвета, шрифты, расположение).
- `render.js` — покадровый рендер в Chromium и сборка MP4 через ffmpeg.
